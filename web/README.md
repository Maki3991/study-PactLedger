# PactLedger Web Runtime

此目录包含当前 React 前端和 Fastify 后端。为避免出现多份互相冲突的说明，完整文档统一维护在仓库根目录：

- [产品说明](../docs/PRODUCT_SPEC.md)
- [开发、测试与部署](../docs/DEVELOPMENT.md)
- [Injective 接入](../docs/INJECTIVE_AGENT_PAYMENT_HANDOFF.md)
- [编程 Agent 约束](../AGENTS.md)

快速开始：进入本目录，准备 PostgreSQL 与 `.env.local`，然后运行 `npm ci`、`npm run dev`。不要从仓库根部旧脚本启动两套后端。
