该仓库为 KaleidoX 参赛项目的方案文档与前端 Demo 展示页面，不包含后端服务、链上执行引擎或任何需要运行时配置的系统。经检查：

- 根目录仅包含 `web/`（React + Vite 前端）、两个 Markdown 设计文档，无 `config/`、`.env*`、`*.yaml`、`*.toml`、`application.properties` 等配置文件。
- `web/vite.config.ts` 仅启用 React 插件，未定义环境变量注入逻辑。
- `web/src/main.tsx` / `App.tsx` 中无任何 `process.env`、`dotenv`、`import config` 等配置加载代码。
- `package.json` 依赖仅为 React、Vite、Lucide 图标库，不含 dotenv、js-yaml、config 等配置管理包。
- 所有“策略参数”“Agent 列表”“防火墙规则”均以硬编码的 `demoData.ts` 静态数据形式存在，不存在分层配置、环境变量覆盖或外部化配置机制。

因此本仓库**不存在**可识别的配置系统，该类别不适用。
